features

Built different.

A terminal AI client that respects your workflow.

Greyscale UI

A quiet monochrome interface that stays out of the way. Focus on the conversation, not the chrome.

Uncensored mode

No content restrictions on responses or the system prompt. What the model knows, it uses.

Multi-provider

OpenRouter, Groq, Google AI Studio, Mistral, Hugging Face and local models. One interface, every backend.

Full session persistence, prompt editing, image and file context, session search.

install

Install.

The best AI to make cheats.

bash · step 1 
# Clone and install
git clone https://github.com/pixel-1coder/vox-cli.git
cd vox-cli
pip install -e .

# Interactive setup wizard (recommended)
vox --setup

# Or manual config
vox --provider ollama --model llama3.1:8b
chat · step 2 
# Start chatting
vox

# Use specific provider/model
vox -p openrouter -m cognitivecomputations/dolphin-mixtral-8x7b
vox -p grok
vox -p ollama -m deepseek-coder:33b

# List available models for provider (CLI flag)
vox --list-models -p openrouter

# Interactive commands (inside chat)
/model_list        # List all models (free/paid, uncensored/regular)
/switchmodels      # Interactive model picker 
/togglefilters     # Switch Unfiltered ↔ Censored mode
